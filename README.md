# Iranos Telegram Manager v0.3.0

## امکانات نسخه سوم
- ذخیره مخاطبان مجاز محلی
- آرشیو حداکثر ۵۰ پیام تبلیغاتی و بارگذاری دوباره
- انتخاب عکس از گالری و اشتراک عکس/متن
- یادآور دوره‌ای با تنظیم ساعت/دقیقه (WorkManager؛ زمان تقریبی)
- گزارش فعالیت
- خروجی و بازیابی فایل JSON از مخاطبان، آرشیو پیام‌ها و گزارش‌ها

## محدودیت‌های حریم خصوصی و ضداسپم
این اپ به حساب تلگرام وارد نمی‌شود، دفترچه تلفن را نمی‌خواند، ارسال خودکار انبوه ندارد و فقط محتوای اشتراک‌گذاری را برای انتخاب دستی مقصد آماده می‌کند. فهرست مخاطبان باید صرفاً شامل افرادی باشد که رضایت دریافت پیام تبلیغاتی داده‌اند.

## ساخت
پروژه را در Android Studio باز کن، Gradle Sync، سپس Build > Build APK(s).
شناسه: ir.iranos.manager
نسخه: 0.3.0
حداقل Android 8.
